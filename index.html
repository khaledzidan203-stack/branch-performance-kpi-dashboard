Analytical Methodology

This synthetic implementation demonstrates a branch KPI framework using generalized operational segments and controlled fictional records. Calculations are performed in JavaScript at row, employee, category and branch levels.

  • Target achievement = Actual Sales ÷ Period Target.
  • Average Basket Value = Sales ÷ Customer Count.
  • Core Retail Basket = Core Retail Sales ÷ Core Retail Customers.
  • Operational Product Rate = Selected Product Sales ÷ Core Retail Sales.
  • Sales status: SAFE ≥ 85%, WATCH 80–84.99%, DANGER < 80%.
  • Operational rate status: SAFE only when the full operational target is achieved.

See KPI_DEFINITIONS.md, BUSINESS_LOGIC.md and the docs folder for detailed assumptions.
