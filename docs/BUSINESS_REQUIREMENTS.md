# Business Requirements

## Objective

Provide a compact management dashboard that helps a retail branch review performance against plan and connect analysis to operational follow-up.

## Functional requirements

| ID | Requirement |
|---|---|
| BR-01 | Show Sales Target and Actual Sales for the selected period. |
| BR-02 | Calculate Achievement % and classify sales performance. |
| BR-03 | Show Customer Count and Average Basket Value. |
| BR-04 | Provide employee performance metrics without allocating branch sales targets to employees. |
| BR-05 | Show product/category actuals and target achievement. |
| BR-06 | Support operational-rate targets and status classifications. |
| BR-07 | Show upcoming activities and reminders. |
| BR-08 | Provide daily trend analysis. |
| BR-09 | Support interactive date, employee, and segment filters. |
| BR-10 | Use only public-safe synthetic data. |
| BR-11 | Require no backend or credentials for the public demo. |
| BR-12 | Keep KPI definitions auditable in repository documentation and source code. |

## Non-functional requirements

- Responsive desktop-first layout.
- Fast local load for a small sample dataset.
- No runtime package dependency.
- Clear status colors with accompanying text labels.
- Portable CSV/JSON sample sources.
- Recruiter-readable documentation.
