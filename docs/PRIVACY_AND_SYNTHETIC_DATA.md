# Privacy and Synthetic Data

## Publication rule

This repository is designed for public portfolio use and contains synthetic data only.

## Excluded content

The repository must not contain:

- real company names or internal brand assets;
- real branch identifiers;
- real employee names or IDs;
- customer names, phone numbers, national identifiers, or transaction identifiers;
- prescription or medical information;
- credentials, API keys, tokens, connection strings, or internal server addresses;
- proprietary source files or exported production datasets;
- confidential company thresholds or terminology where publication could reveal internal operating policy.

## Generalization approach

Business-specific sales channels were renamed to anonymous/public-safe segments such as `Channel A`, `Channel B`, `Channel C`, `Core Retail`, and `Special Channel`.

Names, dates, values, targets, activities, and category results were created solely for demonstration.

## Before future commits

Run a repository-wide search for names, emails, phone numbers, credentials, URLs, company identifiers, production database terms, and copied source exports before pushing to GitHub.
