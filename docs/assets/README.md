# Presentation Assets

This directory contains presentation-only visual assets for the Branch Performance KPI Dashboard project.

## Current overview

`Branch Performance KPI Dashboard.png`

The root README uses this image as a high-level architecture and capability summary.

## Evidence-supported scope

The implemented repository supports:

- synthetic branch-performance data only;
- five application pages;
- three global filters: Date, Employee and Sales Segment;
- target-versus-actual sales tracking;
- customer and Average Basket analysis;
- employee KPI analysis;
- six-category target analysis;
- operational activities and reminders;
- SAFE / WATCH / DANGER status logic from configuration;
- HTML/CSS/Vanilla JavaScript runtime;
- zero runtime package dependencies;
- GitHub Pages deployment;
- SQL and Power BI translation/reference documentation.

## Evidence boundary

The infographic is a presentation schematic, not a literal screenshot of every implemented filter or page.

Authoritative implementation details remain defined by `index.html`, `js/app.js`, the synthetic source files, automated tests, screenshots and project documentation.

SQL is a reference model. Power BI is mapping/design documentation only.
