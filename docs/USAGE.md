# Usage

1. Start the local server and open the dashboard.
2. On **Overview**, review Actual Sales, Achievement %, Customer Count, Average Basket Value, Operational Product Rate, and Active Days.
3. Change the date range to test period-sensitive calculations.
4. Select a fictional employee to isolate employee activity.
5. Select **Core Retail** or **Special Channel** to compare generalized segments.
6. Open **Employees** to compare sales, customer count, basket values, and operational statuses.
7. Open **Categories** to compare actual category sales with targets.
8. Open **Operations** to review synthetic upcoming activities and reminders.
9. Open **Methodology** for an in-app explanation of calculations.

For deeper review, inspect `KPI_DEFINITIONS.md`, `BUSINESS_LOGIC.md`, and `js/app.js`.
