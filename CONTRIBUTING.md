# Contributing

This repository is primarily a portfolio demonstration, but improvements are welcome.

1. Fork the repository and create a focused branch.
2. Keep all example data synthetic and non-identifying.
3. Do not add credentials, internal URLs, customer records, employee records, or proprietary datasets.
4. Document new KPIs in `KPI_DEFINITIONS.md` and `DATA_DICTIONARY.md`.
5. Update `BUSINESS_LOGIC.md` when calculation rules change.
6. Test filtering, denominator-zero behavior, and status thresholds before opening a pull request.
7. Keep the zero-build-dependency goal unless a dependency provides a clear analytical benefit.
