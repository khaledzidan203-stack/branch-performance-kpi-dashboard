# Example Output

Using the included synthetic sample data, the dashboard produces:

- a selected-period sales total and target achievement percentage;
- customer count and Average Basket Value;
- a daily sales trend;
- fictional employee performance rows;
- operational-rate SAFE/DANGER classifications;
- category achievement bars;
- upcoming activity and reminder lists.

Exact values change when the date, employee, or segment filters change. The screenshots folder contains example rendered states from the included dataset.
